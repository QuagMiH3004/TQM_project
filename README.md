# Avalonia Demo App: Learning & Experimentation

## Introduction
This is a cross-platform demo application developed using **C#** and **Avalonia UI**. The primary purpose of this project is for **personal learning, experimentation, and deepening my understanding** of modern GUI application development principles.

It serves as a practical, functional example of leveraging **Avalonia** on **FOSS (Free and Open-Source Software)** operating systems like **Linux (Ubuntu LTS)**.

##  Key Features

* **Cross-Platform UI:** Built with **Avalonia UI** to ensure compatibility and a native look-and-feel across various operating systems (Windows, macOS, Linux, etc.).
* **MVVM Implementation:** Strictly utilizes the **Model-View-ViewModel (MVVM)** design pattern to achieve clear separation between the business logic and the user interface, enhancing maintainability and testability.
* **Core UI Component Demos:** Features essential UI component examples for hands-on learning, including:
    * `Button`
    * `TextBox`
    * `ListBox` / `DataGrid` (Demonstrating data binding)
* *Note: More components will be added as part of ongoing learning and testing.*

##  System Requirements


To build and run this application, you must have the **.NET SDK** installed.

* **SDK:** **.NET 9 (RECOMMENDED)**
* **Operating System:** Tested successfully on **Ubuntu LTS 24.04**. Expected to run on any system supporting .NET and Avalonia.

> **Development Environment Note:** This project was developed and tested on a legacy system: a **Lenovo ThinkPad X230 (i5-3320M) running Ubuntu LTS 24.04**.
